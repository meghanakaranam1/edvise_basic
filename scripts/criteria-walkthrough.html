What to check:
• Attendance — two signals, "ADA Q1" and "ADA Q2". Each dropdown option is a full phrase ("≥10% days missed"), so the meaning doesn't depend on a separate label next to it. Try opening the dropdown, and try Other… to see the custom input (it keeps "% days missed" visible next to the number).
• Course failure — two signals (Math Grade, English Grade) — each subject gets its own independent cutoff, not one shared threshold.
• Behavior — one signal from the Discipline Log sheet (not Roster), with real incident values as checkboxes.
• The checkbox values shown for Behavior come specifically from the Discipline Log sheet's own data — not Roster's — which is the multi-tab bug that was just fixed.
